# **App Name**: Ius

## Core Features:

- Issue Understanding: Use natural language processing to understand the user's legal issue from their description and keywords.
- Flowchart Generation: Generate a visual flowchart explaining the user's rights and options based on their scenario, incorporating relevant laws and articles. The LLM acts as a tool, using reasoning to generate the flowchart based on the information provided.
- Legal Display: Display a clear legal analysis and final interpretation, including specific actions or phrases the user can take, along with a red/green signal indicator representing the severity of the situation.

## Style Guidelines:

- Primary color: Neutral gray (#F5F5F5) for a professional and trustworthy feel.
- Secondary color: Light blue (#E3F2FD) to represent justice and clarity.
- Accent: Teal (#008080) for interactive elements and important calls to action.
- Clear and readable font choices for legal information.
- Use simple, recognizable icons to represent different legal concepts and actions.
- Clean and organized layout to present information in a digestible manner.
- Subtle transitions and animations to guide the user through the legal process.
